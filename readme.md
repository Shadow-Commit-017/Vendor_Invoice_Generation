📌 Project Description

This project is a Machine Learning-based system that predicts freight costs and detects anomalies in invoices. It combines data preprocessing, model training, and a Streamlit-based user interface to provide real-time insights.

The system is divided into two main components:

Freight Cost Prediction – Estimates transportation cost based on input features
Invoice Flagging – Identifies suspicious or irregular invoices

The models are trained using separate notebooks and integrated into a working pipeline using Streamlit.


🎯 Key Features
Predict freight cost using ML models
Detect anomalous invoices
Interactive web interface using Streamlit
End-to-end pipeline from training to deployment


🛠️ Technologies Used
Python
Pandas, NumPy
Scikit-learn
Streamlit
